# Quality Scoring Engine

Score each dimension from 0–10.

## Visual
- Hierarchy
- Typography
- Spacing
- Color
- Components

## Interaction
- Feedback
- Continuity
- State clarity

## Motion
- Purpose
- Timing
- Naturalness

## System
- Consistency
- Responsive behavior
- Accessibility
- Performance

## Interpretation

- 9–10: excellent and production-polished
- 8–8.9: strong, minor refinement needed
- 7–7.9: good foundation, visible weaknesses
- 5–6.9: functional but inconsistent
- below 5: redesign important areas

Final score should not hide critical failures. Accessibility or broken core interaction must be explicitly reported even when averages are high.
