# Component Intelligence

Do not start with a library.

Start with the interaction and UI problem.

## Order of preference

1. Existing project component
2. Existing project primitive
3. Trusted provider
4. Small custom implementation

## Provider intent

- shadcn/ui: foundational accessible application primitives
- Sona UI: premium interaction and motion primitives
- Beautiful UI / BeUI / Rare UI / Great UI: discovery and inspiration sources
- Transitions: transition patterns
- Custom: when existing options create unnecessary complexity

Use `engines/component-decision-engine.md`.
