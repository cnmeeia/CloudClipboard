# Build UI Workflow

1. Understand product goal and target user.
2. Inspect the existing codebase.
3. Define hierarchy and page structure.
4. Reuse existing components.
5. Run Component Decision Engine for missing primitives.
6. Define interaction states.
7. Run Interaction Decision Engine.
8. Add purposeful motion only after states are correct.
9. Implement responsive and accessible behavior.
10. Perform a final audit.
