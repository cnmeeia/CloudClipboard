# Visual Polish Checklist

## Alignment

- [ ] Major elements share a common alignment axis
- [ ] Repeated components are aligned consistently
- [ ] Icons are visually centered
- [ ] Text baselines are consistent
- [ ] Buttons align with parent structure
- [ ] No arbitrary offsets (13px margins, -3px transforms)
- [ ] Grid columns are consistent

## Spacing

- [ ] All spacing uses tokens (no arbitrary px values)
- [ ] Consistent gaps between related elements
- [ ] Padding rhythm is consistent across cards
- [ ] Whitespace creates visual grouping
- [ ] No elements touching or overlapping

## Typography

- [ ] Clear type hierarchy (size + weight + color)
- [ ] Consistent font stack
- [ ] Line height ≥ 1.5 for body text
- [ ] No random font sizes
- [ ] Letter-spacing adjusted for headings/labels
- [ ] Text does not exceed max-width

## Radius

- [ ] All radius values use tokens
- [ ] Parent radius > child radius
- [ ] Consistent radius per component type
- [ ] No random border-radius values
- [ ] Nested elements follow radius hierarchy

## Edges & Surfaces

- [ ] Borders are 1px hairlines with subtle rgba
- [ ] No thick borders or excessive contrast
- [ ] Elevated surfaces have inset top highlight
- [ ] Card separation via shadow + border
- [ ] Consistent shadow levels for elevation
- [ ] No borders compete with content

## Glass

- [ ] Glass surfaces use gradient + blur + saturation
- [ ] Glass reserved for navigation, overlays, premium panels
- [ ] Not every component is glass
- [ ] Blur values within performance limits
- [ ] Glass responds to background visually

## Color

- [ ] Consistent accent color usage
- [ ] Text contrast meets WCAG AA
- [ ] No color-only meaning
- [ ] System/light/dark themes consistent

## Overall

- [ ] UI feels intentional
- [ ] UI feels calm
- [ ] UI feels premium
- [ ] UI feels responsive
- [ ] Nothing feels accidental
- [ ] Nothing feels over-designed
- [ ] Final polish is invisible (felt, not noticed)
