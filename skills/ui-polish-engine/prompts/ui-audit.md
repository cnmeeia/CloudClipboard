Automatic UI Quality Audit

Analyze the interface as a senior:

* Product Designer
* UI Designer
* Frontend Engineer
* Motion Designer

Do not modify code immediately.

First inspect the entire interface.

---

## Evaluate

**Structure**

* layout hierarchy
* grid
* responsive behavior

**Alignment**

* shared axes
* baseline alignment
* icon alignment

**Spacing**

* consistent gaps
* padding rhythm
* whitespace balance

**Radius**

* consistency
* hierarchy
* nesting

**Surface**

* background hierarchy
* card separation
* depth

**Glass**

* blur quality
* transparency
* saturation
* borders

**Motion**

* duration
* easing
* spring physics
* enter / exit transitions
